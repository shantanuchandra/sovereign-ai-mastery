# Module 01 — LinkedIn post draft

If an AI model runs in your country, does that make it sovereign?

I’m working through a more useful question: **who controls the intelligence—and how would we verify that control?**

For an enterprise product team, the first step is to define the scope: national, sectoral, enterprise, or a particular workload. Then ask what control is needed over location, operations, technology choices and legal/contractual obligations.

A region label is not a test result. A model license is not an exit plan. A vendor promise is not a technical control.

The carousel sketches a course-authored framework for turning claims into decisions. It is not a regulatory taxonomy or a certification.

**Which dependency would you investigate first in an enterprise AI deployment: data routing, admin access, model portability, or contractual rights? Why?**
