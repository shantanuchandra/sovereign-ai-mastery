# LinkedIn post draft: where is the enforcing boundary?

If a retrieved document asks an assistant to export records, which component can actually stop the export?

Module 15 follows that question through source permissions, tool capabilities, artifact identity, conventional platform paths and the complete data lifecycle. Its local exercise deliberately supplies a hostile proposal to an independent policy gate. Thirty-five named tests examine bounded fixture behavior; no model or injection detector is evaluated.

A matching checksum beside an artifact still needs a trusted expected identity. A local network still needs authorization. A passing prompt still needs a scoped security claim and realistic negative tests.

The fictional BANK-A example also retains a hard physical-site constraint: external diagnostics remain a conflict even if action-policy tests pass.
