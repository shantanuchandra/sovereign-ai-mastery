## 1. Which failure are you trying to repair?

Missing source content, format failure and slow generation call for different controlled experiments.

**Decision:** Start with raw errors and an unchanged baseline.

Source/scope: Course-authored intervention framework.

## 2. Would retrieval solve the missing-information problem?

If the current authorized document never reaches the prompt, inspect indexing, permissions and context before adapting weights.

**Decision:** Test the suspected component first.

Source/scope: Illustrative diagnosis, not an effectiveness guarantee.

## 3. Does a small adapter remove the base-model dependency?

LoRA learns low-rank updates with frozen base weights. Keep the compatible base, template, configuration and rights evidence.

**Decision:** Reproduce the whole evaluated build.

Source/scope: Hu et al., LoRA abstract; PEFT conceptual guide.

## 4. Can a smaller weight file prove a faster service?

Quantization changes weight representation. Hardware support, task quality, runtime memory and service latency still need measurement.

**Decision:** Measure the resource and task you claim.

Source/scope: Transformers 4.57.3, Quantization overview.

## 5. Did three repeats create twelve Arabic examples?

Four distinct Arabic cases executed three times remain four examples. Preserve unique coverage and execution counts separately.

**Decision:** Keep the missing evaluation visible.

Source/scope: Course lab: eight synthetic cases, not a language benchmark.

## 6. What did the actual CPU experiment establish?

The one-thread median was 0.449638s; two-thread was 0.4364415s. Both failed all four English and four Arabic literal labels.

**Decision:** Observed timing does not authorize a failed task.

Source/scope: Actual local generation, 28 Nov 2026; order not counterbalanced.

## 7. Can external evaluation preserve this premises rule?

An external judge, tracker or fallback crosses the fictional bank boundary. Local inference does not make that path eligible.

**Decision:** Apply the rule to the full lifecycle.

Source/scope: Fictional BANK-A policy, not a statement of UAE law.

## 8. What would justify a bounded release decision?

Require eligible paths, representative task and language evidence, exact build identity, accountable review and demonstrated rollback.

**Decision:** Record gaps, owners and a dated retest.

Source/scope: Educational draft; independent and production reviews pending.
