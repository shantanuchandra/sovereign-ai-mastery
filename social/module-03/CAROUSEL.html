Sovereign AI Mastery / Decision 01

Which sovereignty requirement actually changes the architecture?

Start with an observable business failure. A signed physical-site restriction is a hard gate; a preference for vendor independence is an investment objective.

Decision: identify the authority, asset boundary, prohibited action and test before comparing vendors.

Can a UAE-hosted service satisfy a named-factory rule?

Not merely because the service is in the UAE. The fictional FACTORY-A contract prohibits restricted prompts, embeddings, outputs, telemetry and backups from leaving the named premises.

What if the cloud is cheaper and more accurate?

Sovereign AI Mastery / Decision 04

Who can approve a sovereignty exception?

A PM does not invent legal authority. Business, security, privacy, legal, architecture, operations and procurement have different evidence and decision rights.

Document the named approver, signed exception scope, expiry, and prohibited override conditions.

Sovereign AI Mastery / Decision 05

What happens when the local gateway times out?

A fictional gateway attempts remote fallback. The firewall denies egress, but the application still violated its premises-only routing policy.

Firewall egress PASS is not application policy PASS. Block release; remove remote fallback and retest degraded mode.

Sovereign AI Mastery / Decision 06

Can an air-gapped system call a licence server?

No. The fictional OT-03 policy prohibits inbound and outbound network paths, including support, updates, licence validation and diagnostics.

Require offline licensing, signed offline artifact transfer, local restore and a physical network-path inspection.

Sovereign AI Mastery / Decision 07

Which evidence should expire after a change?

A new model, gateway rule, subprocessor, log sink, backup path or support route can invalidate the prior approval.

Link each requirement to owner, test, evidence timestamp, version and change-triggered reapproval.

What would you put in the board decision?

Present eligible options, rejected alternatives, six measurable outcomes, accountable owners, unresolved tests and a 30/60/90-day roadmap.

Approve a bounded synthetic pilot only after negative tests and signed reviews. Otherwise: HOLD.
