# Can a local RAG assistant still disclose forbidden information?

Where a model runs and which documents a user may read are separate decisions.

A fictional BANK-A employee assistant keeps generation on site. That does not make an HR-only payroll span eligible for an ordinary staff member. Filtering the displayed answer after a global search does not undo the text already sent to ranking, context or diagnostics.

The Module 12 lab runs real sparse-vector retrieval across synthetic tenants and one actual local-model generation. Its six retrieval cases produce the expected document or abstention. The generated answer contains the correct seven-day fact with extra prose, so it fails the declared exact-format rule. The raw result stays visible and release stays withheld.

Which evidence would you ask for before a pilot proceeds?

- Authoritative identity and permissions before candidate scoring.
- Revocation and version tests across context, cache and queued work.
- Separate retrieval, grounding, language and task-format criteria.
- Every OCR, embedding, reranking, diagnostic, support and recovery destination.
