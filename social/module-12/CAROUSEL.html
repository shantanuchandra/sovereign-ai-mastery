Sovereign AI Mastery / RAG 01

Can a local model still disclose another tenant’s data?

Yes. A globally searchable index can pass forbidden evidence to a generator without crossing a national border.

Authorize evidence before ranking.

Sovereign AI Mastery / RAG 02

Which part of the pipeline decides who may read a chunk?

Resolve identity through a trusted boundary. A tenant name or “I am HR” inside a question cannot grant access.

Carry source permissions through the entire request.

Course-authored control design; not an implemented identity provider2 / 8
Sovereign AI Mastery / RAG 03

What can a permission filter after top-k miss?

Forbidden candidates can displace eligible ones. Their text may already have reached ranking, traces or context.

Restrict the candidate set before scoring.

Teaching design; test actual effective service roles3 / 8
Sovereign AI Mastery / RAG 04

Does a citation prove the answer is supported?

A valid source reference shows where context came from. Each material claim still needs a declared support criterion.

Separate retrieval hit, support and task behavior.

Sovereign AI Mastery / RAG 05

What happens when access changes after retrieval?

Previously authorized context can become stale. Cached responses and queued work need a defined revocation boundary too.

Bind context to current source and policy versions.

Fixture rechecks before context; distributed delivery remains untested5 / 8
Sovereign AI Mastery / RAG 06

What did the actual local generation show?

The response contained the correct seven-day fact with extra words. It failed the predeclared exact-format criterion.

Retain raw failures and keep release withheld.

Sovereign AI Mastery / RAG 07

Can a prompt wrapper prevent every malicious instruction?

No. Approved documents can contain hostile instructions. The teaching quarantine flag is a declaration, not a detector.

Keep access and action controls outside the model.
