# Eight model-choice questions

Educational draft; fictional bank, real small-model experiment. Sources inspected 27 November 2026; full quotes/links are in the chapter.

## 1. Do downloadable weights settle the model decision?

They provide an artifact. Rights, runtime, task quality and operating boundaries still need evidence.

Decision: Gate eligibility before comparing scores.

Source/scope: Course-authored model-selection framework.

## 2. What belongs beside the weight file?

Tokenizer, template, configuration, runtime, adapters and dependency versions belong to the evaluated build.

Decision: Rebuild the bundle, then repeat task tests.

Source/scope: Transformers chat-template documentation, checked 27 Nov 2026.

## 3. Can four English answers prove bilingual quality?

No Arabic denominator means missing evidence. Even four Arabic cases are only a tiny observed sample.

Decision: Keep raw responses and separate language counts.

Source/scope: Eight course-authored synthetic prompts; no production benchmark.

## 4. Can a fallback API preserve this air gap?

A fallback that calls an external API crosses the unchanged physical and network boundary, even when its score is better.

Decision: Block the route and retain the requirement.

Source/scope: Fictional BANK-A policy; not a legal conclusion.

## 5. Would you enable custom code before reviewing it?

The real Jais family card requires a custom model class in its example. The bank scenario is hypothetical; no Jais code was executed here.

Decision: Pin and review the actual code and dependencies.

Source/scope: Jais family card, Getting started, checked 27 Nov 2026.

## 6. What did the small-model lab actually test?

Real CPU generation, eight synthetic prompts, local artifact hashes and separate exact-label counts. Python socket denial is a process guard.

Decision: Do not call that physical isolation or bank acceptance.

Source/scope: SmolLM2 pinned public artifacts; observed outputs linked from lab.

## 7. Is a cheaper blocked option a valid comparison?

Invented costs can illustrate break-even. They cannot authorize an endpoint forbidden by the stated boundary.

Decision: Apply hard gates before cost sensitivity.

Source/scope: Course arithmetic; no provider price or capacity claim.

## 8. What would make a model exit credible?

Reconstruct the licensed bundle, restart within the allowed boundary and repeat task, integration and language tests.

Decision: Record the build, owner, evidence gaps and retest.

Source/scope: Educational draft; independent assessment and manual review pending.
