## Q1. Access and permission

A downloaded file demonstrates possession of those bytes. It does not establish the intended entity's permitted use, complete modification materials, provenance, runtime safety or physical operating boundary. OSI Definition 1.0 includes data information, code and parameters in its preferred modification form: https://opensource.org/ai/open-source-ai-definition, checked 27 November 2026. Allocate one point each for possession, terms/scope, modification materials, provenance and limits. Avoid declaring every downloadable model an open-source system.
