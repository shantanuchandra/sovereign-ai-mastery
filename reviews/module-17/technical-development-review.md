## Control findings and limits

- Manifest hashing covers runtime_build plus model/prompt/retrieval/policy/telemetry and declared boundary. Registration copies input; eligibility rehashes retained state and current revocation. Changing runtime requires a new identifier and approval; direct registry mutation invalidates it. The fictional model digest hashes a version string. No weights, authenticated registry, signature or attestation exist.
- Registration, approval and activation are separate methods. They have no real role authentication; process owner controls registries and can change fixture policy. PASS strings are declared fixture evidence rather than signed external test results. Production approver separation, evidence expiry and independent review remain open.
- Boundary inventory includes prompts, responses, OCR, speech, documents, embeddings, weights, registry, logs, traces, metrics, backups, support, activation, updates, failover and removable media plus operator/offline/media review. Each external artifact is denied. Known conflicts dominate missing evidence. Favorable complete declarations remain DECLARED_ONLY; no actual facility, air gap or network isolation was tested.
- Request telemetry uses fixed trusted synthetic tenant handles, immutable digest and strict booleans/numerics; prompt bodies and request IDs are not emitted. A dedupe set retains request IDs in process memory. A digest and operational metadata are not anonymous data. No log authorization, retention, deletion, tamper evidence or multi-tenant service authentication exists.
- The indicator explicitly measures admitted tenant-specific synthetic events; quota denials and duplicates are excluded and need separate production user-facing measures. Failed admitted requests consume quota. An in-memory count is not a time-window rate limit; restart erases state. Unknown/empty observations return NO_DATA. NaN, infinity, booleans-as-numerics, negative latency and invalid targets are rejected.
- Rollback rechecks prior approval and current eligibility, including revocation. It changes a pointer and restores no database, index, permission or external effect. Registry/requests are single-process memory, without transactional durability or distributed concurrency guarantees.
- No model, endpoint, real tokenizer, customer data, money, cloud resources or external enterprise service was used. Token counts are learner-supplied values. Quality/drift, production load, capacity and actual SLO validation remain open.
